Familles de participes passés irréguliers
Terminaison du participeExemple
Verbes en -oir → -upouvoir → pu, vouloir → voulu, savoir → su, devoir → dû, recevoir → reçu
Verbes en -re (plupart) → -uboire → bu, lire → lu, connaître → connu, paraître → paru, croire → cru
Famille -indre / -oindre / -aindre → -int / -ointcraindre → craint, peindre → peint, joindre → joint, atteindre → atteint
Verbes en -rir (ouverts) → -ertouvrir → ouvert, offrir → offert, souffrir → souffert, découvrir → découvert
Verbes en -ire → -itdire → dit, écrire → écrit, interdire → interdit, décrire → décrit
Verbes en -uire → -uitconduire → conduit, produire → produit, traduire → traduit, cuire → cuit
Famille faire → -faitfaire → fait, défaire → défait, refaire → refait
Famille prendre → -prisprendre → pris, apprendre → appris, comprendre → compris, surprendre → surpris
Famille mettre → -mismettre → mis, promettre → promis, remettre → remis, soumettre → soumis
Famille -enir (tenir/venir) → -enuvenir → venu, tenir → tenu, obtenir → obtenu, devenir → devenu
